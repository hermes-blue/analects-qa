# 사료카드 1단계 — 적극적 문체 재수정본

1차에서 유지했던 314장을 전부 다시 읽고 329곳의 표현을 수정했습니다. 5장 이내의 71개 묶음으로 검토하고 자체 평가를 다음 수정에 반영했습니다. 기존에 수정한 184장까지 포함한 **20편 498장 전체 JSON**입니다.

[편별 수정 전후 보기](comparison/README.md)

## 이번 수정 기준

명백한 오류가 없어도 더 자연스럽게 쓸 수 있으면 문장을 재구성했습니다. 사람의 행동을 추상적인 명사나 공간 비유로 표현한 문장, 읽는 방식을 지시하는 상투적 마무리, 직역투와 어색한 호응을 중심으로 다듬었습니다. 문장 나누기와 어순 변경도 적용했습니다. 기존 고사·정보·해석을 유지하며 표현을 고치는 작업입니다.

예: “같은 스승에게 배운 두 사람이 교우의 문턱을 다르게 잡았습니다.” → “같은 스승에게 배웠지만 누구와 벗을 맺을지에 대해서는 생각이 달랐습니다.”

## 파일과 적용 범위

- `01-hakyi.json`부터 `20-yowal.json`까지가 이번 전체 결과입니다. 본문은 `장[].수정본문`입니다.
- `comparison/`: 편별 수정 전후 본문 전체와 수정 이유입니다. 이번에 다듬은 314장만 비교합니다.
- `changes.json`: 부분 문자열 기준 수정 전후와 이유입니다. 동일 구절은 배열 순서대로 적용합니다.
- `reviews.json`: 71개 묶음의 자체 평가와 최종 대조에서 보정한 6곳입니다.
- `validation.json`: 구절 수·변경기록 재적용·본문 외 필드·문단 수·검토 범위 검사입니다.
- `completion.json`: 전체 완료 범위와 편별 장수입니다.

비교 기준은 1차 완료 커밋 `409781758e98d038176934be77a1c9935b884bd7`의 상위 폴더 JSON입니다. 1차에서 수정한 184장은 이번 결과에서도 모든 필드를 그대로 보존했습니다. 이번 314장은 수정본문과 그에 따른 글자수만 갱신했고, 편별 루트에 `문체재수정` 작업 기록을 추가했습니다.

기존 `검수기록`, `상태`, `문체경수정`은 이전 단계 기록입니다. 이번 결과는 `문체재수정`과 `completion.json`을 기준으로 봅니다. 글자수는 1·2편에서 줄바꿈을 포함하고, 3~19편에서는 제외하는 기존 기준을 따랐습니다. 요왈은 원래 글자수 필드가 없습니다.

## 원본과 확인 범위

원본 출처, 요왈 3장 복구 출처, 향당의 앱 배열은 [1차 작업 설명](../README.md)을 따릅니다. 앱 배열에서 제외했던 원본 향당 18장은 [별도 원본](../excluded-original.json)으로 보존되어 있습니다.

작업자가 대상 전체를 읽고 원문과 수정문을 대조했습니다. 별도 평가 모델이나 역사적 사실 재검증을 사용한 작업은 아닙니다. 수정 완료가 모든 문장의 완벽함을 뜻하지는 않습니다. 앱 배포는 수행하지 않았습니다.
