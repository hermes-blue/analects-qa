# 사료카드 1단계 문체 경수정

20편 전체를 5장 이내의 109개 묶음으로 검토했습니다. 앱용 498장 중 184장의 표현 201곳을 다듬고 314장은 유지했습니다. 앱 배열에 없는 원본 향당 18장도 읽은 뒤 별도로 보존했습니다.

## 수정 범위

AI 말투와 직역투를 줄이기 위해 조사, 문장 호응, 어색한 동사 결합과 명사화를 중심으로 수정했습니다. 경문·표제·출전·근거 자료와 본문의 고사·해석·문단 순서는 유지했습니다. 뜻을 좁히거나 단정이 강해지는 수정안은 최종 재검토에서 되돌렸습니다. 역사적 사실을 새로 검증하거나 내용을 다시 집필한 작업은 아닙니다.

원본: `hermes-blue/analects-qa/pilots/astra-prose`, 기준 커밋 `86e70e84e4f2122e9201bc94988181857e690717`. 업로드 직전 원본 19편의 파일 SHA가 그대로인지 확인했습니다. 원본은 덮어쓰지 않았습니다.

## 파일

- `01-hakyi.json`부터 `20-yowal.json`: 편별 결과. 본문 필드는 `장[].수정본문`입니다.
- `changes.json`: 수정 전후의 부분 문자열과 이유. 같은 구절은 배열 순서대로 적용합니다.
- `reviews.json`: 묶음별 자체 평가, 다음 묶음에 적용한 기준, 최종 재검토 기록.
- `validation.json`: 전체 구절, 변경기록 재적용, 본문 외 필드, 문단 수와 글자 수 보존 검사.
- `completion.json`: 최종 범위와 완료 상태.
- `excluded-original.json`: 앱 498장 배열에 없는 원본 `ly-10-18` 보존. 편별 앱용 JSON에는 넣지 않았습니다.
- `originals/20-yowal.json`: 요왈의 경수정 전 복구 원고.

## 요왈과 향당의 배열

원본 astra-prose에는 1~19편만 있어, 요왈 3장은 `hermes-blue/analects`의 `트랙/뉴코퍼스` 브랜치, `docs/_검수/여는말과1단계교체/역검수/묶음/20.txt`에 남은 **1단계 본문 전문**에서 옮겼습니다. 원본 파일 SHA는 `bd581402e92339728dbd77dd7cef23a0813ca949`이며, 복구 출처를 요왈 JSON에 기록했습니다.

향당은 원본 18장 가운데 앱 배열의 17장을 편별 결과에 두고 마지막 장은 별도로 보존했습니다. 따라서 열람한 원고는 499장, 앱용 결과는 498장입니다. 이 구분 외에는 장의 재배치나 통합이 없습니다.

기존 `검수기록`, `상태`, 자료 목록은 원본 작성 당시 기록으로 보존했습니다. 이번 작업의 상태는 `문체경수정`과 `completion.json`에서 확인합니다. 변경한 장의 `글자수`는 편마다 원래 명시한 줄바꿈 포함·제외 기준을 따릅니다. 별도 평가 모델은 사용하지 않았으며 앱 배포는 수행하지 않았습니다.
