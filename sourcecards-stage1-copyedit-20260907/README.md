## 범위
- 주 작업은 장[].수정본문의 AI 말투·직역투·어색한 조사·낱말 결합을 가볍게 손질하는 것.
- 인물, 사료, 사건, 해석, 수치, 인용, 문단 순서, 표제, 구절ID를 보존한다. 내용 재검증이나 새로운 집필을 하지 않는다.
- 원본 본문과 변경 목록을 대조하여 의미·주체·추정 강도를 지킨다. 분명히 좋아지지 않으면 원문 유지.
- '~셈이다', '~보여준다' 등의 단어를 일괄 치환하지 않는다. 문맥상 필요한 설명·유보와 자연스러운 문장은 그대로 둔다.
- 수정 장의 글자수는 실제 본문 길이로 갱신한다. 기존 검수메모 등은 원본 이력이며 이번 사실검수 결과가 아니다.
