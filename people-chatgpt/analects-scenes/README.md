153명을 원래 순서대로 검토했습니다. 등록된 인물-구절 연결은 393개(인물당 평균 2.57개, 중앙값 1개)이며 100명은 구절이 하나입니다. 유효한 382개 설명을 새로 썼고, 인물 연결 오류 11개는 보류했습니다.

## 원본 구조와의 호환

01~16 JSON은 원본 people/과 동일한 파일명·배열·구조를 유지한 전체 사본입니다. 새 설명은 장면의 왜(첫 문단)와 답(다음 문단)에 나누어 담았고, 중복되는 물었다는 빈 문자열로 처리했습니다. 장면의 물음·형광우, 원문·번역·형광·식별자는 유지했습니다. 프로필·표제·사료조각 등 다른 탭도 원본과 같습니다.

**이 16개 호환본에는 연결 오류 11개의 기존 장면이 그대로 남아 있습니다.** 새 원고로 작성한 항목이 아니며, 앱에 적용하기 전에 연결 오류 목록의 위치와 수정 후보를 확인해야 합니다. 연결 오류의 기존 설명을 새 원고처럼 보지 않도록 통합 원고에서는 본문을 null로 구분했습니다.

원본 people/과 다른 작업 폴더는 수정하지 않았습니다. 이번 작업은 이 별도 폴더에 새 원고를 올린 것이며 앱 데이터에 자동 적용한 것은 아닙니다.
