# ChatGPT 인물카드 사료조각 집필·검수 기준

버전: 1.1 / 2026-09-07

## 범위
인물카드 153명의 사료조각 319개를 원본 순서대로 다룬다. 사료조각이 없는 46명은 빈 배열을 유지하며 새 조각을 만들어 넣지 않는다. 프로필과 논어 속 장면은 이 단계의 대상이 아니다.

수정할 칸은 사료조각[].제목과 사료조각[].한줄이다. 출전(고치지 말 것)과 덩이(고치지 말 것)는 그대로 보존한다. 원문·번역의 불일치나 오자가 보이면 교정안과 근거를 별도 검증 필드에 기록한다.

## 집필
- 기존 소개문의 표현을 고쳐 쓰는 대신, 해당 사료의 한문과 번역을 읽고 소개문을 새로 구성한다. 첫 파일의 구조 확인 중 거백옥의 기존 글은 열람했으므로 이를 미열람으로 기록하지 않는다. 이후에는 집필용 화면에서 기존 제목·소개문을 가리고 글자 수와 사료만 읽는다. 초안 완성 뒤 원본과의 변경 내역을 남긴다.
- 소개문은 삼인칭 존댓말로, 아래 사료의 상황과 읽을 대목을 쉽게 짚어 준다. 삼인칭 서술에서는 공자로 호칭을 통일하고, 직접 발화 속 호칭은 화자와의 관계에 맞춘다. 사료 안의 기존 인용·번역은 이 규칙으로 일괄 치환하지 않는다.
- 출전에 없는 행동·표정·심리·동기를 만들지 않는다. 짧은 명단이나 단편 기록을 새 일화처럼 부풀리지 않는다.
- 한 가지 도입을 반복하지 않는다. 상황 제시, 실제 문답의 쟁점, 두 장면의 대비, 기록 형식의 설명, 행동의 전환, 전승의 특징 등 사료에 맞는 방식을 쓴다. 아래 글은·보여 줍니다·무엇일까요를 의무적으로 넣지 않는다.
- 본문을 전부 압축해 결말까지 미리 설명하기보다 읽을 실마리를 준다. 그렇다고 인물의 기본 관계를 숨기거나 억지 수수께끼를 만들지는 않는다.
- 제목은 사건이나 쟁점을 알아볼 수 있게 간결하게 쓴다. 반말·명사형·의문형을 허용한다. 출전에 없는 말을 직접 인용처럼 꾸미지 않는다.
- 공백과 문장부호를 포함해 Unicode 코드포인트로 센다. 소개문은 각 조각의 원래 길이 안팎으로 맞춘다. 20% 이상 차이가 나면 다시 읽되, 불충분한 재료를 허구로 늘리지는 않는다. 평균 길이를 모든 조각에 강제하지 않는다.

## 파일럿과 순차 적용
거백옥 2개를 먼저 작성·평가하고 한 번 보완한 뒤 다음 인물부터 적용한다. 인물별 초안 → 자체 평가 → 효과가 있는 부분만 수정 → 저장·재조회 순서를 지킨다. 5~10명 단위로 반복 표현·분량·사료 연결을 다시 살피고 다음 구간에 반영한다. 개별 평가와 최종 구간 회고를 구분해 기록한다. 자료가 없는 인물도 순서·빈 배열 보존을 확인한다.

## 평가
가독성, 다음 사료와의 연결, 근거의 정확성, 도입·마무리 반복, 분량, 매핑을 점검한다. 삭제량이나 달라진 글자 수를 품질 점수로 쓰지 않는다. 출전의 존재와 역사적 사실로 확증됨을 구별한다. 사료 문면으로 이해되는 범위를 넘어설 때 외부 원문을 확인한다.

## 저장

## 파일럿 이후 적용한 보완
- 상황과 쟁점이 드러나면 뜻을 다시 풀이하는 결말을 덧붙이지 않는다.
- 서로 다른 전승을 한 사람의 확정된 일대기로 합치지 않는다. 반론·비평은 누가 주장하는지 밝힌다.
- 인물 이름이 사료에 나오지 않으면 앞뒤 원문을 확인한다. 연결이 없거나 필요한 인용이 잘렸다면 검토 사항으로 남긴다.
- 전체 검수에서 초기의 공자님 호칭을 삼인칭 공자로 맞췄다. 소개문 319개 모두 원본 글자 수의 ±20% 안으로 조정했다. 평균은 79.1자에서 89.4자로 늘었으므로, 다음 독자 평가에서는 실제 화면의 길이와 반복되는 서술 동사도 함께 본다.
- 319개 사료의 역사성이나 번역 전체를 확증한 작업은 아니다. 오자·번역·출전·인물 연결의 검토 항목을 본문 수정과 분리한다.
