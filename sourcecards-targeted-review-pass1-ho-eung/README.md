## 상태

- 대상: `sourcecards-style-polish/` 편별 JSON 20개
- 범위: 학이 1장 ~ 요왈 3장, **498장 전수검토 완료**
- 수정 필드: `여는말`만
- 이번 표적: **① 호응 오류**
  - 주어와 서술어의 호응
  - 조사·목적어 연결
  - 나열·병렬 구조의 문법적 짝
- 기준 `main`: `d5b2551c620a20739844a5564b7211109be04560`
- 발견 후보: **5장**
- 본문 반영: **0장**
- 승인 상태: **사용자 최종 승인 대기**

이번 회전에서는 길이, 추상성, 표현 반복, `설명합니다·풀이합니다·살핍니다`의 빈도만으로 후보를 만들지 않았습니다. 문법 호응이 실제로 어긋나고 수정 뒤 문장이 분명히 자연스러워지는 경우만 남겼습니다.

예비 검토 폴더 `sourcecards-targeted-review-round1/`의 5건은 정식 전수검토 전 임시 후보였습니다. 그 가운데 양화 13장은 현재 문장의 문법 호응 자체가 깨졌다고 보기는 어려워 이번 1바퀴 후보에서 제외했습니다. 해당 문장은 뒤의 ‘어색한 어휘 결합/직역 구조’ 회전에서 다시 검토합니다. 전수검토 과정에서 학이 13장을 새 후보로 추가했습니다.
