# 사료카드 2단계 — 여는말 문체 교정본

학이부터 요왈까지 20편 498장을 순서대로 검토했습니다. 153장의 여는말을 다듬고 345장은 유지했습니다.

소장님이 승인한 학이 4·12·13장 시안의 방향으로, 정보와 뜻을 유지하며 AI 말투·직역투·어색한 호응을 선별 교정했습니다. 각 편을 마친 뒤 자체 평가를 기록하고 다음 편에 반영했습니다. 내용의 사실 여부나 해석의 타당성을 다시 검수한 작업은 아닙니다.

## 파일
- `01-hakyi.json`부터 `20-yowal.json`: 모든 원본 필드를 그대로 담은 편별 수정본. 달라진 값은 `여는말`뿐입니다.
- `reviews.json`: 편별 검토한 ID, 수정·유지 수, 자체 평가, 다음 편 적용 기준, 수정 전후 문장.
- `completion.json`: 완료 현황, 원본·수정본 파일 SHA, 보충 대기 목록.
- `validation.json`: 장수·ID·배열·비대상 필드 보존 검사 및 GitHub 업로드 대조 결과.

## 교정 기준
1. 자연스러운 문장은 유지합니다. 수정 비율을 목표로 삼지 않습니다.
2. 추상적인 명사 나열, 어색한 조사·서술어, 불필요하게 돌려 말하는 표현을 구체적인 행동 문장으로 풉니다.
3. 다음 사료를 안내하는 역할은 유지합니다. 모든 문장을 같은 도입이나 맺음으로 통일하지 않습니다.
4. 새 사실·해석·교훈을 보태지 않습니다. 원문의 추정·대안·한정을 단정으로 바꾸지 않습니다.
5. 표제·원문·번역·출전과 모든 ID·장 배열은 그대로 둡니다.
6. 원문 보충 대기 7장은 문체를 고치거나 완성본으로 확정하지 않았습니다.

보충 대기: 학이 11, 팔일 21, 태백 17, 자한 23, 자로 14, 양화 23, 자장 12.

## 원본과 적용
원본은 `sourcecards-chatgpt/`에 있으며 이 작업에서는 덮어쓰지 않았습니다. 이 폴더는 별도 문체 교정본입니다. JSON의 기존 머리말 메타데이터도 보존했으며, 이번 작업의 범위와 상태는 이 안내문과 완료 기록을 기준으로 보시면 됩니다.

적용 시 `구절ID`와 `사료토막`으로 대상을 확인하여 `여는말`만 바꾸면 됩니다. `reviews.json`에 원문과 수정문을 함께 보관했습니다.
