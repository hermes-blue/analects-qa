# 사료카드 2단계 · 3차 제안 153장 — 여는말 전체 비교

**사용자 승인에 따라 이번 153개 수정안을 카드 JSON에 반영했습니다.**

앞선 2차 제안 355장은 반영을 마쳤습니다. 그 수정본 498장 전체를 편·장 순서대로 다시 읽고, 추가 수정안 153장을 작성했습니다. 나머지 345장은 이번 검토에서 유지합니다.

왼쪽은 반영 전 표현, 오른쪽은 승인 후 반영한 문장입니다. **달라진 부분은 굵게 표시**했습니다. 각 카드의 여는말 전체를 보여 줍니다.

[바뀌는 부분만 빠르게 보기](proposed-changes-compact.md)

정보와 기존 해석을 유지하는 범위에서 조사·호응, 긴 문장 구조, 부자연스러운 비유와 추상적인 표현을 다듬는 제안입니다. 자연스러움에 대한 선택 사항도 포함되어 있어, 153장 모두를 오류로 판정한 것은 아닙니다.

원문 보충 대기 카드: 팔일 21장, 태백 17장, 자한 23장, 자로 14장, 양화 23장. 이 카드들은 현재 여는말의 표현만 검토했습니다.
