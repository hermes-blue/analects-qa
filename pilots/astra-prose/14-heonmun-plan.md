# 헌문편 집필 전 계획

2026-09-06. 본문 집필 전에 저장한47장 계획. 주자 집주 배열이며 별도 『논어/헌문제14』47장 배열도 전부 대조했다. 두 자료의 번호는 동일하다. 일부 판본의 합장 번호를 확인 없이 추정하여 넣지 않는다. 기준 브랜치 `track/astra-prose`, 기준 커밋 `521cd5bf3faeda6bd9d12f746c61f5d53a76b199`.

기존 materials·옛 사료 원고는 읽거나 재료로 사용하지 않는다. 외부 고전·주석을 독립 조사했다. 일반 독자를 위한 부드러운 존댓말350~400자, 표제는 비존칭. 사건의 흥미와 문장의 자연스러움을 우선하되 본장 여러 절의 뜻을 보존한다. 외부 일화는 이해를 돕는 비교이지 공자의 발언 계기라는 뜻이 아니다.

자로편에서 남은 재료 복귀 전개·일률적인 두 문단·뜻 재정리를 의식하되 유형별 할당량이나 문단 수는 정하지 않는다. 헌문의 실제 인물 문답을 다른 사건으로 교체할 필요는 없다. 전체 초고 뒤 도입·전개·마무리와 도입 출처를 분류하며, 필요한 주석 설명은 유지하고 중복만 선별 시험한다.

## 검수 기록 방식

47장 초고를 먼저 보존한다. 사실·분량·표현 교정은 기초 교정으로 전후를 남긴다. 이 뒤 전체 구조 검수와 선별 시험을 구별한다. 선별 편집이 없거나 시험이 실패해도 그대로 기록한다. 구조 분류 변화가 없으면 없다고 적고, 수치 변화만으로 전편 대비 우수함을 주장하지 않는다. 1~13편 기존 파일은 변경하지 않는다. 다음 위령공편은 자동 진행하지 않는다.
