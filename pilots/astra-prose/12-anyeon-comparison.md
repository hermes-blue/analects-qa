# 안연편 비교 평가

2026-09-06 · 작성자의 자체 편집 평가 · 소장님 검수 전

안연은 선진과 비슷한 수준이다. 사회 제도와 생활의 재료가 더해진 좋은 장은 있지만, 전체 문장이 더 자연스러워졌거나 팔일을 넘어섰다고 단정할 근거는 없다. 안연 9·12·24장은 재료가 본장의 어려운 지점을 직접 풀어 준다. 3·15장에는 같은 뜻을 표현만 바꾸어 다시 설명하는 부분이 남는다.

이번 비교에서는 안연 3·9·12·15·17·18·20·22·24장, 선진 14·21·24장, 팔일 1·6장을 직접 읽고, 각 편의 기존 전체 검수 기록과 통계를 함께 확인했다. 이전 1~12편 전체를 이번에 새로 정독했다는 뜻은 아니다. 판단의 우선순위는 자연스러움·가독성·흥미, 이어 본장 이해이며 사실 정확성은 필수다.

| 기준 | 안연의 상태 | 앞선 편과의 비교 |
|---|---|---|
| 자연스러운 읽기 | 9장의 감세 문답과 12장의 보증 거절은 구체적인 말과 행동이 글을 이끈다 | 선진 14·21·24장의 인물 문답과 비슷한 강점이다 |
| 재료의 흥미와 적합성 | 24장의 학교 평가가 배움·친구·인이라는 본장의 관계를 직접 보여 준다 | 선진 17장의 고시 고사처럼 일부 인물에게 치우치는 문제를 의식한 국소 개선은 있다 |
| 해설의 반복 | 3장은 행하기 어려워 말하기 어렵다는 뜻을 거듭 설명한다. 15장의 옛 관직 이야기는 널리 배우기에 잘 맞지만 약례 부분은 일반적 풀이로 남는다 | 팔일 1·6장의 신분·의례·문답처럼 구체 사정과 논어의 말이 처음부터 맞물리는 수준에는 못 미치는 장이 있다 |
| 편 전체의 구성 | 경문을 그대로 풀어 시작하는 비율은 낮아졌지만 보충 일화 뒤 뜻을 재정리하는 방식이 많다 | 도입의 소재가 달라진 것과 전개의 반복이 줄어든 것은 구별해야 한다 |

## 통계로 확인되는 변화

기존 전체 검수 JSON을 기준으로 비교했다. 분모와 소재가 다르므로 점수로 환산하지 않는다.

| 항목 | 선진 | 안연 |
|---|---:|---:|
| 본장 경문에서 시작 | 20/25 | 9/24 |
| 본문에서 집주·주희 직접 언급 | 18/25 | 12/24 |
| 같은 전개의 최장 연속 | 4장 | 3장 |

안연의 전개는 문답→사정·뜻풀이 9장, 보충재료→본장풀이 9장, 보충재료→본장풀이→재료복귀 5장, 독자물음→문답·관계풀이 1장이다. 끝은 인물 응답 3장과 원전 인물 평가 1장을 제외한 20/24장이 뜻 정리 또는 처음 재료의 재해석이다. 도입의 변화가 마무리의 다양화까지 이어졌다고 보기는 어렵다.

## 자로에 반영할 일

재료를 독립적으로 찾는 현재 방식을 유지한다. 흥미로운 소재를 더 넣는 것보다, 이미 전달한 뜻을 두세 번 바꾸어 말하는 문장을 완성 후 먼저 살핀다. 다만 필요한 해석 안내까지 삭제하거나 모든 장의 끝을 인물 대사로 맞추지는 않는다. 재료가 본장의 여러 절을 고르게 설명하는지도 계속 확인한다.

안연 3·15장은 완주 뒤 선별 검토 후보로 추가한다. 이번에는 기존 안연과 다른 편의 본문을 수정하지 않는다. 이전 안연의 7장 선별 수정은 기초 교정과 별개이며, 그 외 장을 전혀 고치지 않았다는 뜻도 아니다.
