# 이인편 집필 전 계획

2026-09-05 · 논어집주 기준 26장

소장님이 선택하신 팔일편 방식: 경문 독해 → 외부 자료 독립 조사 → 소재 선정 → 유형 선택 → 집필 → 문장·근거 검수. 기존 저장소의 이인 원고·재료·장문 규칙은 참조하지 않습니다. 이전 대화의 원고를 이미 본 사실은 지울 수 없으나 이번 원고의 재료는 외부 경문과 문헌에서 새로 선정합니다.

유형은 사건, 인물·관계, 생활·제도, 비교, 의문·오해의 다섯 가지입니다. 몇 장씩 겹치는 것은 허용하며 균등 배분하거나 모든 장을 다르게 쓰려 하지 않습니다. 본문은 부드러운 존댓말, 표제는 비존칭. 350~400자 안팎에서 이미 드러난 뜻을 되풀이하지 않습니다.

고전의 전승·가정적 비유·후대 주석은 구별합니다. 별도 일화를 해당 발언이 나온 직접 계기로 쓰지 않습니다. 결론 문장이나 인용을 억지로 덧붙이지 않습니다. 문장을 덜어낸 뒤 주어·지시어가 여전히 분명한지 확인합니다.
