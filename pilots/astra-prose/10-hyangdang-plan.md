# 향당편 집필 전 계획

2026-09-06 · 기준 커밋 d2b590233feb0189d652b7051f54589b4f659543

내용과 자연스러운 읽기 우선. 해설자의 안내는 뜻이 통할 때만 덜고 필요한 설명을 희생하지 않는다. 유형을 맞추기 위한 재작성은 하지 않는다. 외부 고전과 주석을 독립 조사했으며 저장소 기존 원고와 materials는 집필 재료로 읽지 않았다. 이전 1~9편 수정은 20편 완료 뒤 검토한다.

주자 집주의 절 구분을 따르되 팔일편과 중출하는 ‘入太廟，每事問’을 별도 14장으로 보존한 18장. 집주 머리말은 17절이라고 하므로 단순히 ‘주자 18장’이라고 표기하지 않는다. 확인한 27장 배열과의 대응은 별도로 남긴다.

## 재료와 사실 구분

- J5: [논어집주 권5](https://zh.wikisource.org/wiki/四書章句集註/論語集注卷五). 향당 경문과 주석. 경문의 행동 기록을 임의의 날짜·인물·대사로 장면화하지 않는다.
- QL1: [예기 곡례 상](https://zh.wikisource.org/wiki/禮記/曲禮上). 장자와 문답, 문턱, 주객의 자리, 다른 나라·집안에 들어갈 때 질문, 승차 줄. 예서 규범을 공자가 실제 겪은 별도 일화로 제시하지 않는다.
- QL2: [예기 곡례 하](https://zh.wikisource.org/wiki/禮記/曲禮下). 집을 지을 때 종묘·마구간과 창고·거처 순서.
- YP: [의례 빙례](https://zh.wikisource.org/wiki/儀禮/聘禮). 접빈의 중개 역할, 사신이 규를 받고 군주 명령을 받는 순서.
- JT: [예기 제통](https://zh.wikisource.org/wiki/禮記/祭統). 재계 때 음악과 잡념을 삼가는 규범. 공자 개인이 정확히 열흘 재계했다는 사실로 옮기지 않는다.
- ZL: [주례 하관사마](https://zh.wikisource.org/wiki/周禮/夏官司馬). 방상씨 복장과 역귀를 쫓는 의식. 왕실 규범과 공자가 본 마을 행사의 규모·복장을 동일시하지 않는다.
- 장배열만 대조: [이우재, 논어 향당 원문 배열](https://incheonin.com/news/articleView.html?idxno=2624). 번역·해설은 집필 재료로 사용하지 않는다.

## 장별 유의점

1~5장: 표정과 걸음의 구체적 변화만으로 의미가 드러나는 곳은 끝에 교훈을 덧붙이지 않는다. 4장 過位는 임금이 서는 자리이지 빈 왕좌가 아니다. 5장 사신 기록의 실제 수행 여부는 집주에서도 의문을 제기하므로 특정 출사 사건으로 꾸미지 않는다.

6·8·13·16장은 여러 절을 묶은 긴 장이다. 경문 전체를 JSON에 보존하되 본문은 핵심 장면을 선택한다. 모든 세칙을 나열해 읽기 어렵게 하지 않는다. 6장 貉는 너구리, 短右袂는 평상시 털옷 오른 소매. 7장 葷은 냄새 강한 채소. 8장 술의 양을 정하지 않았다는 말은 흐트러질 때까지 마셨다는 말이 아니다. 제사 고기의 분배와 식사량을 현대 건강 지침으로 제시하지 않는다.

9장 자리를 바로잡는 말은 방향·신분만을 뜻한다고 단정하지 않는다. 11장 멀리 있는 사람을 향한 절과 약을 받고 하는 절의 대상을 구별한다. 12장 화재 결과나 다친 사람 유무는 원전에 없으므로 채우지 않는다. 13장 산 짐승 선물의 종류를 임의로 특정하지 않는다. 14장은 태묘 중출 구절을 빼지 않는다. 15장 殯은 임시로 관을 모심이지 집에 매장함이 아니다. 16장 負版은 채택한 집주에서는 나라의 도적을 든 사람이며 행상인으로 번역하지 않는다. 17장 綏는 승차할 때 잡는 줄이지 고삐가 아니다. 18장은 子路共之와 三嗅而作의 이설, 주희의 결문 가능성을 남긴다. 이 경우 안내를 삭제하면 사실성이 떨어진다.

## 집필 후 검수

350~400자, 부드러운 존댓말, 다양한 비존칭 표제. 18장 전체 독해와 원전 대조 후 도입·전개·종결을 분류한다. 반복 통계는 위치를 찾는 보조 자료이며 할당량이 아니다. 명확한 이득이 있는 후보만 한 차례 시험한다. 해당 후보가 없으면 구성 수정 0건도 허용한다. 사실·조사·주체 교정과 구조 변경은 구별한다. 소장님 검수 전 11편으로 넘어가지 않는다.
