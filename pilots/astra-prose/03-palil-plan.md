# 팔일편 집필 전 계획

작성일: 2026-09-05 · 검수용 독립 조사 파일럿

기존 저장소의 재료·원고·장문 규칙은 읽지 않고 경문과 외부 고전 문헌으로 조사했습니다. 저장소는 업로드 확인과 JSON 필드 구조만 확인했습니다. 소재를 먼저 고르고 아래 다섯 유형을 유연하게 붙였습니다. 유형별 할당량은 두지 않습니다. 표제는 비존칭, 본문은 부드러운 존댓말로 씁니다. 본문은 공백 포함 350~400자를 목표로 하되 설명을 반복해 분량을 채우지 않습니다.

다른 문헌의 일화는 이해를 돕는 비교 자료이며, 해당 논어 발언의 직접 계기로 쓰지 않습니다. 경문에 없는 인물의 표정·심리·대사는 만들지 않습니다. 후대 주석에 따른 해석은 필요한 곳에서 주체를 밝힙니다. 마무리 초점은 초고 방향이며 고정 문장 틀이 아닙니다.

## 자료 목록

- **J2** [논어집주 권2·팔일](https://zh.wikisource.org/wiki/四書章句集註/論語集注卷二) — 팔일 26장 경문과 주희 및 인용 주석. 후대 해석과 경문을 구분.
  확인 구절: 八佾第三；凡二十六章
- **YONG** [시경·주송·옹](https://zh.wikisource.org/wiki/詩經/雝) — 시 원문
  확인 구절: 相維辟公，天子穆穆
- **M1B** [맹자·양혜왕 하 1](https://zh.wikisource.org/wiki/孟子/梁惠王下) — 왕의 음악을 듣는 백성의 두 반응은 맹자가 설정한 가정
  확인 구절: 今王鼓樂於此；獨樂樂，與人樂樂
- **TAN** [예기·단궁 하](https://zh.wikisource.org/wiki/禮記/檀弓下) — 자로의 가난과 장례 문답, 조문 시점, 두궤의 간언. 예기에 전하는 이야기로 사용
  확인 구절: 子路曰傷哉貧也；周反哭而弔；知悼子卒未葬
- **S33** [사기·노주공세가](https://zh.wikisource.org/wiki/史記/卷033) — 소공 25~32년의 축출과 객사. 3.5 발언 계기로 단정하지 않음
  확인 구절: 三家共伐公，公遂奔；昭公卒於乾矦
- **SHE** [예기·사의](https://zh.wikisource.org/wiki/禮記/射義) — 사례의 몸가짐·음악·명중, 패배 뒤 성찰
  확인 구절: 內志正，外體直；循聲而發
- **MING** [예기·명당위](https://zh.wikisource.org/wiki/禮記/明堂位) — 노나라가 왕실 예악을 받은 유래에 관한 전승
  확인 구절: 命魯公世世祀周公以天子之禮樂
- **JIYI** [예기·제의](https://zh.wikisource.org/wiki/禮記/祭義) — 제사 전 망자를 기억하는 규범적 서술
  확인 구절: 思其居處，思其笑語；齊三日
- **J5** [논어집주 권5·자한 3](https://zh.wikisource.org/wiki/四書章句集註/論語集注卷五) — 모자 재료는 당대 관행을 따르되 절하는 위치는 예를 지킴
  확인 구절: 麻冕，禮也；拜下，禮也
- **M5B** [맹자·만장 하 7](https://zh.wikisource.org/wiki/孟子/萬章下) — 우인 소환 일화. 처형 위협만 기록, 실제 처형으로 쓰지 않음
  확인 구절: 齊景公田，招虞人以旌；以皮冠
- **GUAN** [시경·주남·관저](https://zh.wikisource.org/wiki/詩經/關雎) — 시 원문만 사용. 웹 편집자 현대 주석은 근거로 사용하지 않음
  확인 구절: 輾轉反側；琴瑟友之；鐘鼓樂之
- **J7** [논어집주 권7·헌문](https://zh.wikisource.org/wiki/四書章句集註/論語集注卷七) — 관중 공적을 인정한 공자의 평가와 3.22 비교
  확인 구절: 管仲相桓公，霸諸侯，一匡天下
- **YUE** [예기·악기](https://zh.wikisource.org/wiki/禮記/樂記) — 악무 무의 여섯 대목을 역사와 연결하는 전승
  확인 구절: 總干而山立；始而北出，再成而滅商

## 검수 기준

1. 구체적인 소재가 해당 구절의 이해에 실제로 보탬이 되는가.
2. 소리 내어 읽을 때 한국어 문장으로 자연스러운가.
3. 이미 드러난 뜻을 마지막 문장에서 다시 설명하지 않는가.
4. 인접 장의 도입·전개·종결이 반복되지 않는가.
5. 사료의 전승, 후대 해석, 집필자의 연결 설명이 혼동되지 않는가.

학이·위정·팔일은 대상 구절이 달라 방법의 우열을 확정하는 실험은 아닙니다. 소장님의 세 원고 비교 검수 후, 필요하면 같은 장에 서로 다른 집필 조건을 적용해 확인합니다.
