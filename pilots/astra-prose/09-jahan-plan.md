# 자한편 집필 전 계획

2026-09-06 · 주자 논어집주30장 · 기준 e8fb63bf0a17ddcb6208f33124aa4a999451d8e1

태백21장과 7·18장 채택본을 원격에서 확인했다. 기존 옛 원고·materials는 집필 입력으로 읽지 않는다. 외부 경문·주석·고전에서 독립 조사한다. 현재 파일럿은 앞편 중복 대조에만 사용한다.

## 이번에 옮기는 검수의 무게

소장님 기준은 자연스러움·가독성·흥미가 우선이고 구절 이해가 그다음이다. 사실을 지어내지 않는 원칙은 유지한다. 30장을 다 쓴 뒤 실제 읽는 흐름을 먼저 보고, 이미 전달된 뜻을 다시 말하는 문장, 글 자체를 평하는 문장, 불필요한 오해 차단을 추린다. 문장을 덜면 앞뒤 접속과 주어를 다시 읽는다. 필요한 해석 표시를 없애거나 사건을 과장해서 재미를 만들지 않는다.

350~400자를 목표로 쓰되 같은 내용을 길게 반복해 채우지 않는다. 본문 존댓말·표제 비존칭. 다섯 소재 유형은 선택지이며 수량을 맞추지 않는다. 아래 계획을 본문보다 먼저 저장했다.

## 배열과 중복

6장은 多能 문답과 牢曰을 함께 보존한다. 통상31장 배열의 6·7장이 집주6장에 대응하며 집주7~30장은 통상8~31장이다.

3장(모자·절), 10장(안회 배움), 14장(정악), 26장(자로의 도포), 30장(당체 시)은 앞편 해설에 이미 쓰인 본장 경문이다. 본장을 생략하거나 억지로 다른 일화로 바꾸지 않는다. 20편 완주 후 앞편의 보조 일화를 재배치할 후보로 남긴다. 태백7의 증자 역책은 자한11과 닮아도 다시 쓰지 않는다.
