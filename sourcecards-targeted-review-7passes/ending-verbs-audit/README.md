# 사료카드 2단계 여는말 종결동사 전수조사

- 대상: `sourcecards-style-polish/` 498장
- 현재 `풉니다+풀이합니다`: 131회
- `설명합니다`: 95회
- 수정 후보: 83장
- 전부 반영 시 `풉니다+풀이합니다`: 45회
- 본문 반영: 0건 (승인 대기)

과도한 `풀이합니다`는 여는말이 사료의 내용을 직접 안내하기보다 매번 “무엇을 풀이한다”는 메타 서술로 닫히면서 생긴 반복입니다. 실제 낱말·문구의 뜻풀이에는 유지하고, 해석·판단·비교·원인 파악은 `봅니다`, `읽습니다`, `해석합니다`, `살핍니다`, `짚습니다`, `구별합니다` 등 문장 기능에 맞는 서술로 바꾸는 후보만 제시합니다. `설명합니다`도 95회이므로 단순 대체어로 사용하지 않습니다.
