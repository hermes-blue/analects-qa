## 이번 바퀴

**주어·서술어 호응만** 20편 498장 전체를 검토했습니다.

### 잡는 경우
- 사람의 생각·판단·질문·문제 제기·해석 행위를 `답`, `주석`, `글` 같은 문서·발언 자체가 어색하게 수행하는 문장
- 주어가 빠져 실제로 누가 칭찬·걱정·판단하는지 헷갈리는 문장
- 수정 뒤 실제 행동 주체가 더 분명해지고 문장이 확실히 자연스러워지는 경우

### 잡지 않는 경우
- `『사기』는 전합니다`
- `이 주석은 설명합니다`
- `이 책은 풀이합니다`

위와 같이 한국어에서 자연스럽게 허용되는 문서 주어 표현은 단어 자체만으로 수정하지 않았습니다.

또한 길이, 추상성, 질문문, 카드 간 문장틀 반복, `설명합니다·풀이합니다·살핍니다`의 빈도만으로는 후보를 만들지 않았습니다.
