# 사료카드 2단계 2회전 3바퀴 — `~의` 연쇄·명사 덩어리

- 대상: `sourcecards-style-polish/` 20편 498장, `여는말`만
- 검토 완료: 498/498
- 보조 스캔: 한 문장 안 `의` 글자 2회 이상 101문장
- 최종 후보: 4건
- 현재 상태: 승인대기, 본문 JSON 미반영

## 기준

`~의` 자체를 금지하지 않습니다. `공자님의 말씀`, `주석의 풀이`, `나라의 제도`처럼 자연스러운 소유·관계 표현은 유지했습니다. 한 문장에 `의`가 여러 번 있어도 관계가 분명하고 호흡이 자연스러우면 수정하지 않았습니다. 반대로 소유격과 명사화가 겹쳐 `A의 B에 대한 C의 D`처럼 읽히거나 같은 대상의 `~의`가 거듭 반복되어 문장이 무거워질 때만 후보로 잡았습니다.

## 결과

최종 후보는 공야장 25, 태백 5, 미자 4, 자장 18의 4건입니다. 상세 전후 문장은 `approval-table.md`, 구조화 기록은 `audit.json`, 전체 현재본은 `all-openings-current.md`, 보조 스캔은 `marker-scan.md`를 참고합니다.
