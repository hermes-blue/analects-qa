# 사료카드 2단계 여는말 7바퀴 표적검토 — 6바퀴 `것` 중첩·명사화 과잉

## 범위

- 대상: `sourcecards-style-polish/` 20편 전체
- 장수: **498/498장 전수검토 완료**
- 수정 대상 필드: `여는말`만
- 이번 표적: `것` 중첩, 불필요한 명사화, 그로 인한 AI식 우회 서술
- 승인 후보: **5건**
- 현재 본문 반영: **0건**

## 검토 방식

5바퀴 승인 17건이 반영된 현재 `sourcecards-style-polish/` 20편에서 498개 `여는말`을 다시 추출한 뒤 001번부터 498번까지 순서대로 전부 읽었습니다.

이번 바퀴에서는 다음만 후보로 잡았습니다.

- `것`이 겹쳐 문장이 한 번 더 감싸지는 경우
- 직접 동작을 쓸 수 있는데 `~한 것은`, `~하는 것은`으로 우회한 경우
- `기준은 ~ 여부`, `설명은 ~ 근거를 보여 준다`처럼 명사화가 겹쳐 AI식·번역식으로 굳은 경우
- 추상명사 주어 때문에 실제 판단·행동 주체가 흐려진 경우

다음은 후보에서 제외했습니다.

- `A와 B는 어떻게 다른가` 같은 자연스러운 비교 구조
- 정의나 강조에 필요한 `것`
- 자연스러운 추상명사 주어
- 단순히 문장이 길다는 이유의 수정
- 수정 후 자연스러움이 분명히 좋아지지 않는 경우
