# 사료카드 2단계 여는말 7바퀴 표적검토 — 7바퀴 직역투·피동·우회 서술

## 범위

- 대상: `sourcecards-style-polish/` 20편 전체
- 장수: **498/498장 전수검토 완료**
- 수정 대상 필드: `여는말`만
- 이번 표적: 직역투, 불필요한 피동, `~하게 되다`, AI식 우회 서술 잔존분
- 승인 후보: **7건**
- 현재 본문 반영: **0건 — 승인 대기**

## 검토 방식

6바퀴 승인 5건이 반영된 현재본에서 498개 `여는말`을 새로 추출해 001~498 순서로 모두 읽었습니다. 이어 피동·우회 서술과 자주 함께 나타나는 표지어를 별도로 검색해 49장을 다시 대조했습니다.

표지어 적중 자체는 수정 사유로 삼지 않았습니다. `식량이 끊긴`, `말이 실려 있다`, `받아들일 준비가 되다`, `받아들여지다`처럼 문맥상 자연스러운 피동과 상태 변화는 유지했습니다. `~을 통해`, `바탕으로`, `관련되다`도 자연스러우면 그대로 두었습니다.

최종 후보는 사람을 억지로 피동 주어로 세운 경우, 자료·답변·말을 추상적 주어로 앞세워 내용을 우회한 경우, `~을 통해 + 명사형 마무리`가 겹쳐 번역문처럼 읽히는 경우 가운데 수정 후가 분명히 자연스러운 7건입니다.
