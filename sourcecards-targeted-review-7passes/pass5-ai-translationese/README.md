## 이번 바퀴의 기준

이번 검토는 문장을 전반적으로 더 세련되게 만드는 작업이 아닙니다. 사람이 자연스럽게 쓰기보다 AI가 정보를 정리하며 만든 듯한 구조와 번역문 같은 어순을 우선해서 찾았습니다.

주로 다음을 보았습니다.

- `~한 대화입니다`, `~한 자료입니다`처럼 실제 행동을 이름표로 바꾸는 명사형 마무리
- `답변에서 ~을 살핍니다`, `A와 B를 연결해 C의 문제를 말합니다`처럼 한 번 돌아서 말하는 AI식 우회 서술
- 한국어 어순보다 번역문의 어순에 가까운 목적어·주어 배치
- 명사와 관형어가 겹치면서 문장이 굳는 경우
- `~의`가 이어져 사람이나 행동을 직접 쓰는 편이 훨씬 자연스러운 경우

다만 아래는 **그 자체로 수정 이유가 아닙니다.**

- 추상명사가 주어라는 이유만으로 고치지 않음. 예: `공자님의 답은 달랐습니다`는 자연스러우므로 유지
- `~의`가 있다는 이유만으로 고치지 않음. 소유·관계 표현에 자연스럽거나 필요한 `~의`는 유지
- `설명합니다·풀이합니다·살핍니다`가 반복된다는 이유만으로 고치지 않음
- 문장이 길거나 추상적이라는 이유만으로 고치지 않음
- 질문절이나 카드 간 문장 틀의 반복은 표적으로 삼지 않음

기존 정보·해석·조건·부정·추정의 강도는 그대로 유지합니다.
