## 검토 방식

현재 `sourcecards-style-polish/` 20편에서 498개 `여는말`을 다시 추출해 `all-openings-current.md`에 고정한 뒤, 001번부터 498번까지 순서대로 전부 읽었습니다.

이번 바퀴에서는 다음만 후보로 잡았습니다.

- 앞 문장에서 이미 전달한 뜻을 바로 뒤 문장에서 다시 요약하는 경우
- 같은 설명 역할을 두 문장이 연달아 반복하는 경우
- 두 문장을 합치거나 한쪽을 덜어도 기존 정보와 해석이 그대로 남는 경우

다음은 후보에서 제외했습니다.

- 같은 낱말이 반복되지만 문장 역할이 다른 경우
- 문장이 길거나 추상적이라는 이유만의 수정
- 질문절이나 카드 간 문장 틀의 반복
- `설명합니다·풀이합니다·살핍니다`의 단순 빈도
- `~한 대화입니다`, `~한 이야기입니다` 같은 명사형 마무리 자체 — 이는 5바퀴에서 별도 검토
- 수정 후 개선이 분명하지 않은 경우
