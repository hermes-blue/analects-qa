## 검토 방식

현재 `sourcecards-style-polish/` 20편에서 498개 `여는말`을 다시 추출해 `all-openings-current.md`에 고정한 뒤, 001번부터 498번까지 순서대로 전부 읽었습니다.

이번 바퀴에서는 다음만 후보로 잡았습니다.

- 명사와 절이 같은 나열에 묶여 문법 구조가 어긋난 경우
- 연결형과 의문절이 한 서술어에 병렬되어 읽는 흐름이 흔들리는 경우
- 서로 다른 성격의 비교 대상을 동등한 항목처럼 놓아 비교 관계가 어색해진 경우

다음은 후보에서 제외했습니다.

- 서로 다른 내용을 단순히 함께 다루는 정상적인 나열
- 문장이 길거나 추상적이라는 이유만의 수정
- 질문절 자체나 카드 간 문장 틀의 반복
- `설명합니다·풀이합니다·살핍니다` 같은 말의 빈도 자체
- 수정 후 개선이 분명하지 않은 경우
