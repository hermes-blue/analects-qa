# 사료카드 「여는말」 — 말투를 다듬어 주십시오

논어 앱의 **2단계 사료카드 498장**에 들어가는 글입니다.
사료카드는 논어 한 장마다 **옛 책에 나온 관련 기록**을 붙인 카드입니다.
그 카드에서 **한문 원문이 나오기 바로 앞에 놓이는 두어 줄 설명**이 「여는말」이고,
지금 그 여는말에 AI 말투가 남아 있어 그것을 걷어 내는 일을 부탁드립니다.

## 파일
`sourcecards/NN-편이름.json` 20개 — 논어 스무 편이 한 편에 한 파일입니다. 합쳐 498장.
한 장이 이런 꼴입니다.

```json
{
  "구절ID": "ly-01-01",          ← 어디에 넣을지 찾는 열쇠
  "편": "학이", "장": 1, "편장": "학이 1",
  "사료토막": 5455,               ← 되꽂는 열쇠
  "고칠칸": "여는말",
  "여는말": "과거에 떨어진 이언평은 책을 읽으라는 말에도 마음이 풀리지 않았습니다. …",
  "_읽기용": {
    "머리한문": "學而時習之", "머리독음": "학이시습지",
    "표제": "낙방 뒤에 배움을 묻다",
    "구절설명": "『논어』 첫머리의 세 마디",
    "출전": "정수덕, 《논어집석》(論語集釋)",
    "원문덩이": [{"한문": "仲脩中選，而某被黜。…", "우리말": "조효손 중수(송나라 선비)가 …"}]
  }
}
```

## ✅고칠 칸 — 여기 하나뿐입니다
**`여는말`.** 다른 칸은 손대지 마십시오.

## ⛔고치면 안 되는 칸
`_읽기용` 안의 **모든 칸**입니다 — 한문 원문·우리말 번역·표제·구절설명·출전.
옛 기록 그대로라 한 글자도 바꾸면 안 됩니다. 뜻을 알아야 여는말을 고칠 수 있어서 함께 넣었을 뿐,
읽기용입니다. `구절ID`·`사료토막`·`편`·`장`도 그대로 두십시오 — 이것으로 어디에 넣을지 찾습니다.

## 여는말이 무슨 글인가
카드에서 이런 자리에 놓입니다.

```
표제        낙방 뒤에 배움을 묻다
여는말  ←   과거에 떨어진 이언평은 …          ★이 두어 줄
─────────────────────────────
한문 원문   仲脩中選，而某被黜。…
우리말      조효손 중수가 급제하고 …
```

**원문을 읽기 전에 「지금 무슨 이야기가 나오는지」를 미리 알려 주는 안내문**입니다.
그래서 짧아야 하고(두 문장 안팎), 원문에 나올 이야기를 앞질러 다 말해 버리면 안 됩니다.

## 어떻게 고치나
1. **길이를 지킵니다.** 지금과 비슷하게 두 문장 안팎.
2. **AI 말투를 걷어 냅니다.**
   - 「~라고 할 수 있습니다」 「~인 셈입니다」 「중요한 것은 ~입니다」 같은 늘어지는 맺음
   - 앞 문장을 되풀이해 요약하는 마무리
   - 「이 일화는 ~을 보여줍니다」처럼 뜻을 대신 정리해 주는 문장
3. **원문에 없는 사실을 만들지 마십시오.** `_읽기용`에 있는 것만 씁니다.
4. **공자는 늘 「공자님」**이라 부릅니다. 부드러운 존댓말입니다.
5. 사람 이름이 처음 나오면 누구인지 짧게 붙입니다(원문 번역에 있는 만큼만).
