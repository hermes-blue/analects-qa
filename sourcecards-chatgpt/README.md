# 사료카드 표제·여는말 새 집필

## 완료 현황

20편 498장을 순서대로 모두 검토했다. 원문이 있는 491장의 표제와 여는말을 새로 작성했으며, 원문이 비어 있는 7장은 보충 대기다. 5장씩 99묶음과 마지막 3장 1묶음, 총 100회의 자체 평가를 기록했다.

보충 대기: 학이11, 팔일21, 태백17, 자한23, 자로14, 양화23, 자장12. 이 7장의 기존 표제·여는말은 파일 구조 보존을 위해 남겼으며 신규 원고로 확정한 것이 아니다.

`completion.json`에 편별 장수와 보류 목록, `validation.json`에 전체 필드 보존 및 분량 검사 결과가 있다. 일부 본문의 발췌 생략과 번역·화자 불일치는 해당 묶음 평가에 남겼다. 본문은 교정하지 않았다.

2026-09-07 소장님 지시: 기존 표제·여는말을 참고하거나 문장별로 고쳐 쓰지 않는다. 사료 본문의 한문과 우리말 해석, 출전만 읽고 새로 쓴다. 기존 여는말은 글자 수만 확인한다.

## 작업 범위

- 새 원고는 이 폴더의 편별 JSON에 반영한다. 원본 sourcecards 폴더는 보존한다.
- 바꾸는 값은 `여는말`과 `_읽기용.표제` 두 칸이다. 원본 안내문의 표제 수정 금지는 이후 소장님의 표제 신규 집필 지시로 변경되었다.
- 한문, 본문 해석, 출전, 기타 읽기용 필드, 모든 ID와 장 배열은 그대로 보존한다.
- 원문이 비어 있는 장은 임의로 내용을 만들지 않고 보충 대기로 남긴다. 원래 문장을 최종 신규 원고로 간주하지 않는다.

## 집필 기준

1. 표제는 본문의 중심 내용이 직관적으로 드러나고 읽고 싶어지게 쓴다. 실제 원문에 없는 사건·감정·결론을 만들지 않는다.
2. 여는말은 짧은 줄거리 요약으로 끝내지 않고, 독자가 다음에 어떤 글을 읽을지 알려 준다. 낯선 인물·상황·쟁점을 먼저 풀어 준다.
3. 상황 안내, 질문 제시, 학자·출전 소개, 비교 안내, 배경 안내, 대화 안내를 본문에 맞게 선택한다. '아래 글', '다음 글'을 반복하지 않는다. 의문형이나 '설명합니다'도 고정 틀로 삼지 않는다.
4. '~인 셈입니다', '~을 보여줍니다', '중요한 것은', 번역식 명사 나열과 추상적인 끝맺음을 피한다. 독자에게 불필요한 과제를 주지 않는다.
5. 부드러운 존댓말을 쓴다. 공자님 호칭을 지킨다. 공자님이 직접 하신 말씀과 후대 학자의 풀이를 구별한다.
6. 여는말은 원래 분량과 비슷하게, 두 문장 안팎으로 쓴다. 글자 수를 채우려 설명을 덧붙이지 않는다.

## 순차 작업

학이 1장부터 요왈 끝까지 5장씩 묶는다. 각 묶음을 집필한 뒤 본문 근거·자연스러운 문장·본문 안내 기능·표제 적합성·직전 묶음과의 반복을 평가한다. 평가를 reviews/NNN.json에 기록하고 다음 묶음에 적용한다. 편 경계에서 남는 장은 다음 편과 함께 묶는다. 평가는 이 작성자의 자체 편집 판단이며 독립 독자 검증은 아니다.

진행 여부는 reviews와 validation.json에서 확인한다. 아직 작성하지 않은 장이나 원문 보충 대기 장은 신규 작성 완료로 계산하지 않는다.
