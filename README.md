# analects-qa — 논어 구절 사전 문답(問) 받는 통로

> 여기는 **JSON 만 오가는 통로**입니다. 앱 코드도 데이터도 여기 없습니다.

## 무엇을 넣나

논어 한 장(章)마다 **물음 3개와 답 3개**. `받은것/` 폴더에 넣습니다.

```
받은것/ly-01-01.json      한 장에 한 파일
받은것/학이-01-10.json    또는 여러 장을 배열로 묶어도 됩니다
```

## 틀

```json
{"구절ID":"ly-01-01",
 "問":[{"물음":"...","답":"..."},
       {"물음":"...","답":"..."},
       {"물음":"...","답":"..."}]}
```

묶음으로 넣을 때는 배열로 감싸면 됩니다.

```json
[{"구절ID":"ly-01-01","問":[...]},
 {"구절ID":"ly-01-02","問":[...]}]
```

## 구절ID 붙이는 법

`ly-편번호-장번호` — 두 자리로 맞춥니다.

```
ly-01-01   학이 1장        ly-02-05   위정 5장
ly-13-03   자로 3장        ly-20-03   요왈 3장
```
편 번호 = 학이 01 · 위정 02 · 팔일 03 · 이인 04 · 공야장 05 · 옹야 06 · 술이 07 ·
태백 08 · 자한 09 · 향당 10 · 선진 11 · 안연 12 · 자로 13 · 헌문 14 · 위령공 15 ·
계씨 16 · 양화 17 · 미자 18 · 자장 19 · 요왈 20

## 물음과 답을 쓰는 법

```
물음   논어를 처음 읽는 사람이 이 장에서 실제로 걸릴 것
답     100~150자. 말끝은 존댓말
```
- 낱말 뜻풀이는 하지 않습니다. 그건 다른 칸에서 이미 합니다.
- **그 말이 나온 상황, 그때 사정, 왜 하필 그렇게 말했는지** — 구체적인 것을 씁니다.
- 원문을 다른 말로 바꿔 되풀이하는 답은 쓰지 않습니다.

## 받는 쪽

`받은것/`에 올라온 것을 기계가 가져가 검문하고 본 저장소에 넣습니다.
**여기 파일은 지우지 않고 그대로 둡니다** — 원본이 남게 하기 위해서입니다.
