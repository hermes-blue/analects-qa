# stories/ — 1단계 옛이야기 (편별 JSON)

> 논어 한 장마다 **그 말이 나온 자리의 옛이야기**를 붙인 글입니다.
> 한 파일 = 한 편. `01-hakyi.json` … `20-yowal.json`

## 틀

```json
{ "갈래":"1단계 옛이야기", "편번호":1, "편이름":"학이", "장수":16,
  "장":[ { "구절ID":"ly-01-01", "장":1, "출전":"『논어』 학이 1",
           "표제":"학이시습 (學而時習) — 배우고 때로 익히면",
           "본문":"기원전 55년에 …",
           "그림":[ {"설명":"…", "점":[{"이름":"행단(杏壇)","풀이":"…"}]} ] } ] }
```

## ⛔고칠 때 지킬 것

```
① "구절ID" 는 ⟪절대 바꾸지 않는다⟫ — 어느 장인지 알아보는 유일한 표다
② 장을 ⟪빼거나 순서를 바꾸지 않는다⟫ — 장수와 개수가 맞아야 받는다
③ 고친 것을 돌려줄 때도 ⟪같은 틀⟫ 그대로 (키 이름을 바꾸지 않는다)
④ 긴 글을 「…(생략)」 으로 줄이지 않는다 — 줄이면 그 편은 통째로 버린다
```

## 받는 쪽이 하는 검문

```
장 수 · 구절ID 순서 · ★엉뚱한 편 섞임 · 표제/본문 글자 대조 · 그림·점 개수 · JSON 성립
```
