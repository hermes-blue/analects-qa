# _옛판/ — ⛔여기 것은 쓰지 마십시오

> 2026-09-03 소장님 지시로 내려온 것입니다. **지운 것이 아니라 옮긴 것**입니다.

## 왜 내렸나
글을 통째로 주고받던 방식을 **⟪재료⟫를 주고받는 방식**으로 바꿨습니다.
글이 눈앞에 있으면 「문장을 따르지 말라」고 해도 결국 따라가기 때문입니다.

```
지금 쓰는 것 = materials/     사실 조각 목록. 이것만 보고 글을 새로 씁니다
```

## 여기 든 것
```
stories/         1단계 옛이야기 글 20편 498장  (2026-09-03 올렸던 것)
rewritten-v1/    그 글을 고친 판 4편          (학이·위정·팔일·이인)
rewritten-v2/    이인편 자유 재구성판
```

## 되돌리려면
`git mv _옛판/stories stories` 처럼 도로 옮기면 됩니다. git 이력에 다 남아 있습니다.
