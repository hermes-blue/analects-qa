# 논어 사료글 재구성 규칙

> 상태: 자유 재구성 시험판 v0.9  
> 목적: 규칙이 문장을 대신하지 않게 하고, 장마다 가장 잘 읽히는 글을 만든다.

## 1. 글의 목적

논어의 각 장이 무슨 뜻인지, 왜 이런 말이 나왔는지를 처음 읽는 사람도 흥미롭고 쉽게 이해하도록 쓴다. 경문만 다시 풀어 쓰는 데 그치지 않는다. 도움이 된다면 인물 이야기, 역사적 사건, 당시의 제도와 생활, 주요 주석, 다른 장의 관련 구절 등을 자유롭게 활용한다.

## 2. 기존 글의 취급

기존 JSON의 본문은 반드시 살려야 하는 초고가 아니다. 쓸 만한 사실이 있을 때 참고하는 자료일 뿐이다.

- 기존 내용을 일부만 쓰거나 전혀 쓰지 않아도 된다.
- 기존 순서와 구성, 문장, 시작과 끝을 따르지 않는다.
- 더 나은 재료가 있으면 기존 재료를 버리고 바꿀 수 있다.
- 문장 몇 개를 고치는 방식이 아니라 장마다 새 글을 쓴다.

## 3. 자유로운 작성

글의 형식과 구성에는 별도의 틀을 두지 않는다. 일화로 시작해도 되고, 질문이나 경문부터 꺼내도 되며, 낱말·제도·논쟁을 중심에 놓아도 된다. 인용문의 위치, 문단 수, 문장의 길이, 끝맺음도 장의 내용에 맞게 정한다.

모든 장에 같은 구조를 반복할 필요가 없다. 주희의 풀이, 역사 일화, 현대적 설명, 결론을 의무적으로 넣지 않는다. 자연스럽고 이해하기 좋은 글이 되는지를 우선한다.

## 4. 사실성

사실을 지어내지 않는다. 널리 알려진 사료·주석·역사적 맥락은 적극적으로 보충할 수 있다. 견해가 갈리는 내용은 하나의 사실로 단정하지 않으며, 주석가의 해석을 공자님의 직접 발언처럼 섞지 않는다. 확실하지 않은 세부는 빼거나 불확실성을 밝힌다.

## 5. 분량

- 기본 목표: 공백 포함 350자 안팎
- 대체로 300~420자 범위
- 내용에 따라 조금 짧거나 길어질 수 있다.
- 글자 수를 맞추려고 정보를 빼거나 쓸데없는 문장을 덧붙이지 않는다.

## 6. 파일 처리

- 원본 `stories/` 파일은 수정하지 않는다.
- 장 수, 장 번호, 구절 ID, 출전은 원본과 일치시킨다.
- 새 시험본은 이전 수정본과 비교할 수 있도록 별도 경로에 저장한다.
- 저장 전후로 JSON 파싱, 누락·중복·빈 본문을 확인한다.
