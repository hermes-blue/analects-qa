## 원본과 적용 방법

원본 저장소는 `hermes-blue/analects`, 브랜치는 `트랙/뉴코퍼스`입니다. 원본 경로는 `1차완성본/쉬운설명카드/01-학이.html`부터 `20-요왈.html`이며, 확인한 커밋은 `40dc71fe2376f34ae3343c25cd683b7e3cf0c85b`입니다.

이 JSON은 **선택한 텍스트 필드의 교체 자료**입니다. 카드 전체 본문이나 HTML을 대체하지 않습니다.

| 항목 | 적용 대상 | 식별 방법 |
|---|---|---|
| 이 장의 핵심 | `article.card > .big > p.hx`의 텍스트 | 카드 `id`와 `original` |
| 한자 풀이 | `details.st1 .w`의 설명 `p` | 카드 `id`, 단어 순번 `index`, `label`, `original` |
| 의문 | `details.st2 .qs > li`의 `p.q` 또는 `p.a` | 카드 `id`, 문답 순번 `index`, `field`, `original` |
| 쟁점 | `details.st3 .js .side > p` | 카드 `id`, 쟁점 순번 `index`, 견해 순번 `side`, `heading`, `label`, `original` |

순번은 모두 1부터 시작합니다. 식별 정보와 현재 원문이 모두 일치할 때만 `changed: true` 항목의 텍스트를 `revised`로 바꿉니다. 원문이 달라졌으면 자동으로 덮어쓰지 않습니다. 한자 표제·독음·학자 표기·쟁점 제목·인용문·이미지와 HTML 구조는 그대로 둡니다.

나머지 세 항목 6,423개 텍스트 필드의 원문과 순서를 원본 HTML에 대조했습니다. 수정한 124개는 한자·숫자·따옴표 안의 표현이 유지되는지 확인했습니다. 선택한 본문 텍스트만 교체하는 모의 적용에서 카드 순서와 HTML 태그가 보존되는지도 확인했습니다. 편별 JSON 60개는 업로드 후 다시 읽어 작성한 내용과 일치하는지 대조했습니다.
