# 쉬운 설명 카드 — 문체 다듬기

소장님 지시: 내용 검수는 하지 않고, 뜻이 유지되면서 읽기만 분명히 편해지는 문장 일부만 다듬는다. 잘 읽히는 문장은 그대로 둔다.

## 현재 완료 범위

**‘이 장의 핵심’ 20편 498개 검토 완료: 69개 수정, 429개 보존.**
학이편을 먼저 검토하고 자체 평가한 뒤 다음 편에 적용해 요왈편까지 순서대로 진행했다. 각 편 JSON의 self_review에 평가와 다음 편 적용 기준을 기록했다.

- `이장의핵심-전체.json`: 498개 전체의 원문·수정문·수정 여부·이유, 편별 자체 평가.
- `이장의핵심-변경내역.json`: 실제로 수정한 69개만 모은 목록.
- `이장의핵심/`: 20개 편별 JSON.
- `작업현황.json`: 편별 개수, 원문·ID·장 배열·업로드 대조 결과와 다음 회차 상태.
- `수정규칙.json`: 내용 보존 및 순차 검토 원칙.

이 JSON은 **핵심 문장 교체용 자료**이며 카드 전체 본문을 대체하는 파일이 아니다. 語·問·說은 아직 수정하지 않았다. 다음 순서는 語 전체 → 問 전체 → 說 전체다.

## 원본과 적용 방법

원본: `hermes-blue/analects`, 브랜치 `트랙/뉴코퍼스`, `1차완성본/쉬운설명카드/01-학이.html`부터 `20-요왈.html`.
확인한 커밋: `40dc71fe2376f34ae3343c25cd683b7e3cf0c85b`.

원본 HTML은 그대로 보존했다. 수정본을 적용할 때는 해당 `article.card`의 `id`와 `p.hx`의 현재 문장이 JSON의 `id`, `original`과 모두 같은지 확인한다. `changed: true`인 항목만 `revised`로 바꾼다. 원문이 달라졌으면 자동으로 덮어쓰지 않는다. 낙관 이미지 태그, 다른 세 칸, 장 순서와 화면 구조는 그대로 둔다.

## 편집 강도

문장 길이나 문체를 일괄 통일하지 않았다. ‘보여 준다’도 자연스러우면 보존했다. 애매한 비유를 새 해석으로 풀어 쓰지 않았다. 내용의 맞고 틀림을 판정하거나 자료를 보충하지 않았다. 단정·추정·조건·비교·부정을 유지하는 것을 우선했다.

자체 평가는 작성자의 편집 판단이며 독립된 독자 검증이나 내용 정확성 인증이 아니다.
