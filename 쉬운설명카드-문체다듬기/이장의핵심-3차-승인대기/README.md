# 이 장의 핵심 — 3차 승인 반영 완료

**40개 전체 승인 · 수정본 JSON 반영 완료**

2차 반영본의 498문장을 재검토해 제안한 40개를 사용자 승인에 따라 모두 반영했습니다. 나머지 458개 문장은 그대로 유지했습니다. 최초 원문 대비 누적 수정은 366개입니다.

[수정제안.json](수정제안.json)은 승인된 40개의 최초 원문·반영 전 문장·반영 문장을 담습니다. [전체검토.json](전체검토.json)은 498개 검토 기록과 편별 자체 평가를 보존합니다. `current`는 3차 반영 전 문장, `proposed`는 이번에 승인·반영한 문장입니다.

최신 수정본은 상위 폴더의 [이장의핵심-전체.json](../이장의핵심-전체.json)과 `이장의핵심/`의 편별 JSON입니다. 이 폴더 이름은 기존 링크와 검토 이력을 보존하기 위해 유지합니다. 원본 HTML은 수정하지 않았습니다.
