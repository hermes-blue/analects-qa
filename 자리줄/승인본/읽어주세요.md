# 자리 줄·주석 승인본

소장님이 검토하고 올리라고 지시하신 문구를 모은 곳입니다. 자리 줄은 메인 설명 뒤에 표시할 내용이고, 주석 보완은 같은 갈래 카드들이 공유할 인용·풀이·출처입니다. 입력 자료와 승인된 결과를 구별하여 다음 세션이 그대로 사용할 수 있도록 두 파일로 나누었습니다.

생성 출처: MSI 로컬 · Codex · 2026-09-10.

## 현재 승인 범위

- `자리줄-001-010.json`: 학이 1장 1절 자리 1~10, 열 자리 전부 작성. `{자리, 글}` 형식입니다.
- `주석보완-001-010.json`: 而-1·時-2·之-1·不-3·亦-2의 새 주석 다섯 건. `보완안` 배열이 승인된 반영 목록이며, `기존유지`의 다섯 갈래는 변경하지 않습니다.
- 기준 입력: main `2015e4a85e1f7236b61d8d2e74fe52b3a23bcacb`.
- 사용자 승인: 2026-09-10 “제이슨에 올리고”.
- 검토 때 보여드린 자리 설명·인용·풀이·출처를 그대로 보존했습니다.

## 사용 방법

자리 줄 파일의 `자리`를 자리표와 연결하고, 그 자리의 `갈래ID`로 메인 `설명_2단계`를 찾습니다. 메인 뒤에 `글`을 이어서 표시합니다. 검토 화면에서는 `메인 / 새 설명`으로 구분하지만 슬래시는 데이터의 `글`에 넣지 않습니다.

주석은 자리별이 아니라 갈래별이므로 `갈래ID`로 연결합니다. 이번 전달은 승인본 JSON을 공유 저장소에 올리는 단계입니다. 입력 장부·편별 자리표·합본에 결과를 덮어쓰거나 앱 DB를 변경하는 작업은 수행하지 않습니다.

## 경과와 검증

처음에는 기존 자리 줄과 겹치는 곳을 비웠습니다. 이후 소장님이 입력에서 `이미있는줄`을 없애시고 첫 글자부터 다시 쓰라고 하셨으므로, 메인 내용 뒤에 직접 이어지는 열 문장을 새로 제시했습니다. 슬래시 구분과 주석까지 함께 검토받은 뒤 업로드 지시를 받았습니다. 그보다 앞선 자리 1~5 파일럿과 자리 6~15 초안은 보류되어 여기에 포함되지 않습니다.

각 자리의 번호·글자 위치·갈래 연결·40~110자 분량을 확인합니다. 주석 다섯 건은 원래 인용이 빈 갈래인지 확인하고, 웹 원문 링크와 확인 방식을 함께 보존합니다. 주석은 웹 전사본에서 확인했으며 영인본 대조는 하지 않았습니다. 不의 인용은 《시집전》에서 같은 반문 뜻을 풀이한 것이고, 논어 학이장의 직접 주석으로 표시하지 않습니다.

쓰기 방식의 다섯 유형은 [작성유형-5가지.md](../작성유형-5가지.md)에 있습니다. 해당 문서의 예문은 설명용이며, 여기 실린 승인 문장을 자동 교체하지 않습니다.
