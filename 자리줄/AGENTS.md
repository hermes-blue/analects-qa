# 자리 줄 작업 규칙

- 사용자 호칭은 소장님, 존댓말을 사용합니다.
- 입력 안내는 `읽어주세요.md`, 현재 진행은 저장소 루트 `HANDOFF.md`를 읽습니다.
- 현재 구조는 `설명_2단계`(공통 메인) + 자리별 새 설명입니다. 입력에서 삭제된 `이미있는줄`·`옛설명`을 되살려 판단하지 않습니다.
- 새 문장 작성 전 `작성유형-5가지.md`를 읽고, 해당 글자에 도움이 되는 유형으로 씁니다. 한 가지 시작말·설명 방식이 반복되면 묶음 단위로 살핍니다. 유형별 개수 할당은 하지 않습니다.
- 자리 줄은 1~2문장, 40~110자이며 새 정보가 없으면 빈칸으로 둡니다. 기본 뜻 반복·줄거리·교훈·억지 문법 설명을 피합니다.
- 소장님 검토 시 `메인 내용 / 새 자리 설명`으로 나누고 새 설명만 굵게 표시합니다. 아래에 주석 원문·풀이·출처와 기존 유지/새 보완/미확인 상태를 보여 드립니다.
- 주석 조사는 자리 줄과 함께 진행합니다. 빈 갈래에 해당 뜻의 옛 주석을 찾아 근거 링크를 보존하고, 확인하지 못하면 비웁니다.
- 갈래 카드가 없는 59자리는 소장님 지시로 보류입니다. 임의로 갈래를 만들지 않습니다.
- 승인된 전달 결과는 `승인본/`에 둡니다. 자리별 `{자리, 글}` JSON과 갈래별 주석 보완 JSON을 구별합니다. 입력 메인·자리표를 결과 칸으로 전용하지 않습니다.
- 새 문장·주석은 사용자 승인 뒤에만 커밋·업로드합니다. 이미 받은 업로드 지시는 해당 승인 범위에서 실행하고 같은 승인을 다시 묻지 않습니다. 원격 최신 상태 확인, 무관한 변경 보존, 업로드 후 검증을 수행합니다.
