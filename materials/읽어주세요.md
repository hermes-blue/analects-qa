# materials/ — ⟪재료⟫ (글이 아니라 사실 조각 목록)

> `stories/` 의 글에서 **사실 조각만 뽑아 목록으로** 만든 것입니다.
> **글을 처음부터 새로 쓸 때 쓰는 재료**이고, 원래 글은 보지 않아도 됩니다.

## 왜 이렇게 주나
글을 통째로 주면 「문장을 따르지 말라」고 해도 **결국 그 문장을 따라가게 됩니다.**
재료만 주면 **진짜로 새로 쓸 수 있습니다.**

## 틀

```json
{ "갈래":"이인편 재료", "편번호":4, "편이름":"이인", "장수":26,
  "장":[ { "구절ID":"ly-04-01", "장":1,
           "재료":["里仁爲美 = 어진 이가 사는 마을이 아름다움",
                   "마을 선택은 농사·혼인·매장까지 정함",
                   "里 = '머물다'라는 뜻으로도 읽힘"] } ] }
```

## ⛔지킬 것
```
① "구절ID" 는 절대 바꾸지 않는다
② 재료에 없는 사실을 ⟪지어내지 않는다⟫
③ 재료 한 줄 = 사실 한 조각. 40자를 넘지 않는다
```

## 어떻게 뽑았나 (이인편 · 2026-09-03)
```
워커가 뽑고 → 기계 검문(장수·한자 누락·40자 초과·줄 수·한글 깨짐) → 워커 역검수
역검수 결과 = 엉뚱한 장 섞임 ✅없음 · 지어낸 것 ✅없음
```
⚠️그림 설명·점 풀이에서 온 재료도 섞여 있습니다(예: 「공수한 모습으로 그려짐」).
글에 안 쓰실 것은 그냥 안 쓰시면 됩니다.
